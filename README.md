# Academic personal website

Static HTML/CSS/JS site ready for GitHub Pages.

## Replace placeholders
- Name/email/affiliation throughout the HTML files.
- Put the portrait at `assets/images/portrait.jpg`, then replace the portrait placeholder in `index.html` with `<img src="assets/images/portrait.jpg" alt="Portrait of ...">`.
- Put the CV at `assets/docs/cv.pdf`.
- For the Research banner, replace the gradient `<div>` inside `.banner` with `<img src="assets/images/research-banner.jpg" alt="">`.
- Add paper abstracts, links and figure images in `research.html`.

## Publish with GitHub Pages
Upload the contents of this folder to a GitHub repository. In the repository settings, enable GitHub Pages and deploy from the main branch/root folder.
